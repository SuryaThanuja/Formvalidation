# Product List React App (Hooks + Axios)

## What this is
A simple Product List web application built with **React functional components** using **React Hooks** (`useState`, `useEffect`) and **Axios** for the API call.

The app fetches product data from *https://fakestoreapi.com/products* and shows them in a responsive card grid.

## How to run locally

1. Make sure you have Node.js and npm installed.
2. Unzip the project folder (this ZIP).
3. In a terminal inside the project folder, run:

```
npm install
npm start
```

4. The app will open at `http://localhost:3000`.

## Notes
- State management is done via `useState`.
- API call is performed inside `useEffect` using `axios`.
- Only functional components are used.
- The app uses the public Fake Store API. Ensure your machine has internet access when running.
