# React Form (Vite)
Last Updated: 07 Aug, 2025

## Setup
```bash
npm install
npm run dev
```

The app will be available at `http://localhost:5173`.

## What’s inside
- Form built with HTML inputs (text, email, radio, checkbox, select, textarea)
- State managed via `useState`
- `Reset` and `Submit` buttons
- Submitted data preview (JSON) below the form
