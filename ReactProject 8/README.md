# Quiz App using ReactJS

This is a simple quiz application built with React (class components) and Bootstrap. The project is configured to run with Vite.

## Run locally

1. Install dependencies:
   ```
   npm install
   ```

2. Run development server:
   ```
   npm run dev
   ```

3. Open http://localhost:5173/ in your browser.

## Notes
- This project uses class components for demonstration.
- Questions are stored in `src/components/QuestionBank.js`. Add more to extend the quiz.
